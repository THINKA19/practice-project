# 顾客注册

页面入口：/pages/auth/register/index。index.vue 只装配表单和生命周期；composables/ 管理提交、错误和导航；models/ 管理类型与校验；api/endpoints.ts 是本领域路径清单。Mock 仅从独立 mock/ 入口登记，不从公共 index.ts 引入。

账号为 3–32 位字母、数字或下划线；注册密码为 8–64 位，密码不自动 trim。必须勾选协议，不持久化密码或自动勾选。提交防重复、错误可重试、密码默认隐藏。注册成功返回登录并保留账号与原始目标页，不自动伪造登录。
