# 内核工具参考

本目录已从生产源码迁出，保留为历史参考。
日期、金额、ID、轮询、事件和存储工具仅供参考，正式业务禁止直接或间接导入。按 [使用规范](../../ai/脚手架保护与参考代码使用规范.md) 只提取当前需求所需实现，不需要另设基础设施装配层。
这些工具不依赖页面和 store；有状态的工具需要由调用方负责停止、清理或配置。
请求错误使用 src/http 已有类型和工具，不在这里重复定义 ApiError 或业务错误码。
新增功能先检查脚手架是否已有实现，确有重复使用需求再补充工具与对应测试。

带前缀的存储 clear 仅删除该前缀的键，需要驱动提供 keys()；不支持枚举时返回 false，不退化为全量删除。空前缀 clear 会清空整个驱动，失败返回 false；删除中途失败可能已部分清理。

金额转换按十进制四舍五入，中点远离零（1.255 CNY → 126 分，-1.255 → -126 分）。乘法先舍入单价，再乘数量并舍入小计；整数中间值或结果超出安全范围时抛出 RangeError。调用方应先校验外部金额，并明确单价精度与舍入规则。

轮询仅保证同一轮次串行；stop/start 不取消旧网络请求，调用方仍需在写状态前检查 tick.active。

本目录及其测试不属于正式源码与自动测试集，迁移状态和阅读方式见 [参考资料索引](../README.md)。
