# 平台能力参考契约

本目录从 src/utils/shared/platform 整体迁出，仅作为历史参考，正式业务禁止直接或间接导入。遵循 [使用规范](../../ai/脚手架保护与参考代码使用规范.md)，非必要不修改，按实际需求提取最小实现。下文说明参考函数的行为，不代表项目已接入这些能力。

宿主能力封装保留在 device.ts，编译期平台差异使用条件编译。
异步能力失败抛出 PlatformError，reason 为 Unsupported、Denied、Cancelled 或 System。
original 保留原始宿主错误；detail=privacy 表示隐私授权问题。
上层通过 reason 判断，showError 对主动取消不弹错误提示。
业务状态结果（如 checkSession 的布尔值）保留其原有语义。
宿主新错误码须依据实际响应补充映射；未知错误归为 System。

requestPayment 当前仅支持微信小程序支付参数，其他编译平台返回 Unsupported；显式注册的测试替身优先。需要 App 支付时再扩展独立参数契约。

withLoading 使用并发计数，最后一个任务结束后关闭遮罩，显示首个任务的标题；运行期间不要混用手动 showLoading/hideLoading。

## 迁移状态

- 正式导航和纯文字提示见 [项目工具说明](../../../src/utils/project/README.md)。两者仅提取当前需要的能力，并非本参考库的完整替代。
- 保留模块之间的相对引用及 `__tests__`，便于理解历史行为；删除无调用方的统一导出入口 `index.ts`，不提供旧路径兼容转发。
- 示例中的相对导入只描述参考文件之间的关系，不是业务接入方式。`@/` 引用仍指向迁出时的项目上下文，本目录不是独立可运行的公共包。
- 原有测试作为历史资料保留，不属于当前正式测试集；不新增自动运行配置。如需采用其中能力，提取后在正式目录迁移必要测试并验证实际调用方。
- 当前 TypeScript 和 Vitest 的 include 仅覆盖 src，不扫描本目录；ESLint 显式忽略 docs/reference。目录移出 src 不替代依赖检查，禁止从正式源码导入参考目录。
- 尚未提取的确认框、Loading、返回、外链等不视为项目已实现能力。参考代码不与正式实现双向同步。
