# 骑手登录

微信小程序在真实接口配置就绪时展示原生「微信手机号一键登录」，并提供账号密码入口。H5 和未配置微信接口的环境直接展示账密。页面显示账号由门店开通及管理员重置密码的引导。

- `api/` 使用公共 HTTP 交换候选凭证，具体路径与数据见 [登录数据契约](docs/db.md)。
- `composables/` 编排登录、退出和回跳，由 `@/pages/auth/session` 校验身份并保存唯一会话。
- `mock/` 提供开发演示账密，候选凭证由共享 Session Mock 签发。
- `__tests__/` 覆盖账密、工作台访问、微信双 code、授权取消、迟到响应和退出。

上线前在目标 AppID 核对手机号组件权限、号码范围、额度和隐私指引。确认现有骑手具备可用账密后再下线原骑手短信服务。真实配送业务配置见 [骑手分包说明](../../README.md)。
