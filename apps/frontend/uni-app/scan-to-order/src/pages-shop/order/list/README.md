# 门店订单中心

[订单中心](../index/index.vue)提供分类入口，[订单列表](index.vue)处理分类及工作台快捷入口，[订单详情](../detail/index.vue)处理单笔订单。旧订单中心链接上的 `category` 或 `filter` 会转到列表。

列表负责待处理、今日和历史订单的搜索、筛选与前台刷新。`store/` 缓存当前门店可见的订单，授权上下文变化后清空缓存。列表与[详情](../detail/README.md)各自加载数据，共享基础模型和履约操作。

开发环境列表 Mock 持有唯一的门店订单记录，详情 Mock 的履约写入直接更新该记录。真实服务的查询与接口边界见[接口参考](docs/db.md)。
