# 商家门店上下文与配置

唯一 merchant-shop-context store 保存可用门店、当前门店、授权版本与请求 revision。老板默认可管理A/B两店，员工只进入授权门店。切换先核实目标授权；失败保留原有效门店。乱序响应、换账号及撤权会废弃旧数据上下文。最近门店偏好按操作人和环境隔离。

配置由当前门店读取和按版本保存。名称、营业状态、地址、配送参数及语音总开关持久化在模拟后端；自动接单和自动打印尚未接通，页面禁用。发生版本冲突可重新加载设置。

API路径统一登记于本领域api/endpoints.ts；跨领域调用仅经index.ts。Mock环境使用本地服务；生产接口没有已核实契约，禁止把模拟权限当成真实服务端授权。后端参考见[docs/db.md](./docs/db.md)。
