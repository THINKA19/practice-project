# 商家工作台

老板与员工共用工作台，门店、岗位和操作按当前授权显示。顶部显示当前门店营业状态。多店账号可从顶部切换门店，切店后加载目标门店概览。左上角确认退出后返回客户端「我的」。员工管理内可查看商家编号及进入「所属门店与邀请」。老板可打开今日订单、今日流水和待处理订单，流水按统计权限展示。老板和员工共用首页和菜单布局。员工登录后直接进入工作台。员工按门店授权查看待处理订单和履约入口。

进入或返回工作台时加载门店授权和概览。工作台在前台监听当前门店订单事件并刷新概览及角标。开启店铺语音通知后，新订单自动播报。部分 H5 浏览器需要先点击「试听播报」。微信小程序部署时可通过 `VITE_SHOP_NEW_ORDER_AUDIO_URL` 和 `VITE_SHOP_READY_AUDIO_URL` 配置 HTTPS 语音资源。订单列表与接单、出餐、交付等操作通过「订单管理」进入。通过「骑手管理」可查看当前门店授权的联系人、复制号码和拨打电话。

API路径统一登记于本领域api/endpoints.ts；跨领域调用仅经index.ts。Mock环境使用本地服务；生产接口没有已核实契约，禁止把模拟权限当成真实服务端授权。后端参考见[docs/db.md](./docs/db.md)。

开发环境启用 Mock 后，有当前门店订单查看权限的账号均可在工作台点击「模拟新订单」，验证当前门店待处理数、角标及播报。真实扫码下单需要服务端在订单进入待接单状态后，将 `new-order` 事件写入所属门店的 `/operator/shop/events` 事件流。
