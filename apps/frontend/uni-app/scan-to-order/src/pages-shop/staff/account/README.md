# 商家账号

页面展示唯一已认证后台身份和当前门店岗位，提供进入工作台、所属门店与邀请和退出账号。左上角箭头在确认退出后回到客户端「我的」，退出账号按钮在确认后回到商家登录页。账号不另建凭证store，不显示固定手机号或虚构实名资料。

身份互斥与凭证恢复由 shared/session 负责，权限刷新通过商家公开入口。真实个人资料和改密码服务尚未接通。

API路径统一登记于本领域api/endpoints.ts；跨领域调用仅经index.ts。Mock环境使用本地服务；生产接口没有已核实契约，禁止把模拟权限当成真实服务端授权。后端参考见[docs/db.md](./docs/db.md)。
