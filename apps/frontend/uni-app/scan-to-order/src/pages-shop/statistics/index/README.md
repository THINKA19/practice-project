# 门店经营汇总

按当前门店筛选今日、昨日或近 7 天，默认近 7 天。系统累计独立于期间筛选，展示累计净收款、累计实收、累计退款和累计有效订单。商品销量榜下方显示订单渠道数量。日期筛选和实际起止日期固定在顶部，核心指标位于滚动区首位。每日柱状图从左到右按门店当地日期排列，点击可查看当天金额，最高和最低仅比较已结束日期。每日订单金额按下单时间统计非取消订单，包含未收款订单。

读取汇总需要 statistics.read，展示金额同时要求 order.amount.read。顶部的时间筛选和刷新按钮随页面滚动保持在顶部。

财务概览展示净收款、实收、退款和截至当前的待收款。开发 Mock 按收款和退款成功事件聚合，缺少数据的指标显示「暂未接入」。商品销量 TOP 10 按商品 ID 或旧订单的商品名称动态聚合。开发统计通过订单模块的只读 Mock 入口读取演示数据，聚合规则归统计模块。生产页面通过统计 API 获取汇总。后端聚合协议见 [docs/db.md](./docs/db.md)。
