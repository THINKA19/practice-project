# 个人中心

页面入口仅为 `index.vue`，UI 放在 `components/`，页面逻辑为 `composables/usePage.ts`，跳转为 `composables/useNavigation.ts`。

独立页面分别为 `../feedback/index.vue`、`../code/index.vue`、`../test/index.vue`，均为简单测试页面。导航复用公共 navigate 和 pages/routes.ts 路径。

账户资料读取正式 pages/auth/session，资产未接接口时显示占位符，核销权限未接入时隐藏。文案使用语言包 account 资源，菜单无右侧箭头。

整页通过固定 z-paging 容器进行内部滚动，关闭页面级滚动、自动请求、下拉刷新和加载更多，保留既有内容和样式。

历史反馈提交与会员码逻辑保留在各自页面目录，当前测试页不调用旧接口，未迁移依赖不能视作真实业务已接通。

资产摘要：通过既有 HTTP 调用本模块开发 Mock，有效客户会话返回 3 张券、128.50 元、260 积分，页面不展示演示说明和版本页脚。生产接口未接通，关闭开发 Mock 时不发起演示接口请求。首次加载使用占位块；无数据使用横杠占位；同账户刷新失败保留已有数字，不展示错误文字或重试按钮；进入页面自动刷新。换账户、退出和销毁后丢弃过期响应。金额契约见 models/assets.ts，演示金额单位为分。


余额、优惠券、积分统一使用白色卡片与相同数值字号；无数据不显示错误/空态文案。开发 Mock 摘要使用既有客户归属解析，支持页面刷新后仅恢复开发凭证的演示场景；只返回固定公开样本，不模拟真实服务授权。每次进入账户页经 HTTP 重新获取摘要，禁用响应缓存。

本页导航在进行中的跳转结束前合并连续点击，避免重复压入页面；成功或失败后均解除锁定。账户页独立回归覆盖各入口、组件渲染、内部滚动配置、资产刷新合并及账户隔离。
