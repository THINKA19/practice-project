## 表及关联

## 已知操作语义

cms/page/info/v2 通过 key 查找，返回 info.title/content；key 不是数据库表名。暂无页面时允许 null，页面标题按已返回的标题更新。

## 本模块接口及参数

- `cmsPage(key: string)`：GET `/cms/page/info/v2`；secondary 网关，关闭自动认证。 允许后端暂无数据，按接口函数转换为空列表/对象或 null。

参数签名表示当前前端封装；Record/ApiParams 容器不代表后端接受任意字段。对象序列化与默认值以对应接口函数为准。各接口具体读取/写入的表、事务和连带更新均需后端确认。

## 字段和枚举

以下类型来自前端声明。`?` 只表示前端允许缺省，不表示 SQL NULL；字段声明不是运行时校验。未注明的金额单位、时间格式、默认值和枚举全集均待核实。嵌套字段只是接口嵌套，不证明数据库关联。

### CmsPage

- `info`：`{ title?: string content?: string [k: string]: unknown }`。已声明的前端字段；完整业务含义待后端确认。
- `info.title?`：`string`。标题。
- `info.content?`：`string`。内容。
- `info.contact?`：`string`。可选联系方式；缺省时不显示复制按钮。
