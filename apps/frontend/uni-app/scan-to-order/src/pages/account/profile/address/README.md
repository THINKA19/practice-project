# 收货地址

负责地址列表、编辑、默认地址选择和配送国家选择。页面路径 `/pages/account/profile/address/index`。

未登录进入页面时保留空态新增入口，不请求账户地址；点击新增才引导顾客登录，登录前不打开填写表单。取消登录返回后仍可再次点击新增；顾客登录后刷新列表，再点击新增进入表单。保存前再次检查顾客登录状态，退出或切换账户时清空表单和地址数据。

- `api/address.ts`：地址和行政区接口；路径集中在 `api/endpoints.ts`。
- `models/types.ts`：接口对象、提交类型、地址展示与表单校验。
- `composables/`：页面状态、保存流程和地区选择。
- `components/`：地址编辑表单。
- `index.ts`：向结算领域提供地址类型和地址接口。

依赖公共会话、平台反馈/导航能力。选中地址后先调用更新接口设为默认，再返回结算页；本地表单不是最终服务端事实。电话支持中国、越南、老挝、泰国、印尼区号，保存为国际格式。配送国家为越南、老挝、泰国、印尼、马来西亚；省／城市通过国家关联的白底选择面板选择，街道门牌号填写在详细地址，不强制地图定位。

修改接口或字段前阅读 [后端数据参考](./docs/db.md)。本文档和 db.md 不参与运行。

当前依赖边界、服务接入限制和验证方法见 [profile 迁移说明](../README.md)。本模块未做真实后端或真机验收。

管理页地址卡内容不可点击，只有编辑按钮进入编辑；设为默认成功后更新标签并留在本页。结算选择入口使用 `?select=1`，点击设为默认成功后返回。编辑保留原默认状态，首次新增默认选中；加载详情期间禁止提交。

开发模式通过本模块 mock/entry.mock.ts 登记地址接口，按顾客隔离，首次为空；支持增删改、默认切换，不代表真实保存。页面文案位于 locale 的 account.profile.address。

页面底色及编辑表单外侧使用浅灰 #F5F6F8；顶栏、表单卡片、地址卡及选择弹层使用纯白 #FFFFFF，空态内容整体居中，主按钮保留珊瑚粉渐变，取消按钮为白底灰色圆角描边；页头使用常规字重。联系人等五项合为一张白色表单卡；必填提示靠左，星号与文字垂直对齐。地址卡姓名与电话左对齐，默认标签跟随电话，右侧编辑／删除在卡片内垂直居中，左边框用按钮粉色。地区来自 models/types.ts 的业务配置，当前为部分省市选项，不代表全国配送承诺或完整行政区库。

返回按钮由页面业务处理：编辑中返回列表，列表有页面栈时返回上一页，没有上一页或返回失败时回到首页。当前默认标签不可操作，选择模式重复选择默认地址不再提交更新。默认标记在接口边界规范化，国家与地区校验分别提示。删除确认期间锁定操作，保存／删除后等待列表刷新。

手机号输入框失焦后显示行内红色错误提示；修正号码后提示自动消失，切换区号会重新校验。保存仍由表单和页面业务校验拦截。

手机号空值不因失焦或切换区号提前报错；重新聚焦编辑时隐藏旧错误，失焦读取最新输入再校验，主动保存仍校验必填。设置默认成功后新默认置顶，其余地址保持相对顺序；刷新列表也执行默认优先。

## 当前目录与职责边界

本模块位于 `src/pages/account/profile/address`。页面入口仅接入页面配置、组件及组合函数；原有具名页面路径保持不变。

- 页面入口：`index.vue`
- 对外能力：经 `index.ts` 导出 `addressApi`、`Address`。
- 依赖领域：`@/pages/auth/session`、`@/pages/routes`
- 外部调用只走所属模块的 `index.ts`；模块内部直接引用实现，避免从自身聚合出口绕回。

### 文件职责

- `api/`：请求与原始 DTO；端点集中在 endpoints.ts，不执行响应转换或页面状态修改。
- `models/`：types.ts 为前端模型；enums.ts 为实际使用的常量；mappers.ts 负责边界数据转换，仅以 import type 引用 DTO。
- `composables/`：领域状态、请求编排、权限和交互流程；按职责拆分，每个页面实例的交互状态独立。
- `components/`：业务 UI；入口为组件目录内的 index.vue；私有逻辑就近放置，复合组件的私有子部件放 parts/。
- `domain/`：不依赖 Vue、Pinia、HTTP 和页面运行时的纯业务规则。
- `mock/`：仅开发模拟；entry.mock.ts 沿用现有发现机制，跨 Mock 仅通过 mock/index.ts。
- `docs/`：业务契约、后端接入与参考资料。

### 状态归属

- 共享身份、凭证和用户资料：唯一事实源仍为 `@/pages/auth/session`，本模块不复制会话。
- `composables/use-page.ts`：所属职责的状态或流程；页面通过它获取数据及执行操作。
- `composables/use-requests.ts`：所属职责的状态或流程；页面通过它获取数据及执行操作。
- `composables/use-view.ts`：所属职责的状态或流程；页面通过它获取数据及执行操作。
- `components/AddressEditForm/use-address-edit-form.ts`：组件实例私有的交互状态，不接管领域共享状态。

### 验证

在应用根目录使用 `pnpm test:run --maxWorkers=2`、`pnpm type-check`、`pnpm lint`；构建使用 `pnpm build:h5` 和 `pnpm build:mp`。局部测试或构建通过不代表真实后端、支付或真机能力验证通过。

### Composable 命名

本模块 Domain 为 `Address`。文件使用 `composables/use-<duty>.ts`，实际组合函数导出为 `useAddress<Duty>`；文件名省略领域前缀。请求对象、普通命令和类型保留业务语义，不伪装成组合函数。组件私有 Hook 继续放在组件目录。
