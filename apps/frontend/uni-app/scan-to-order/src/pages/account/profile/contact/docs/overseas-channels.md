# 海外渠道申请、接入与运营

核对日期：2026-10-25。此文为运营接入指引，不代表已经创建、验证或运营任何外部账号。Meta 部分帮助页访问时要求登录，以运营者登录后的实际界面和资格为准。

## 页面顺序与职责

默认演示顺序：微信客服 → 微信公众号 → QQ 客服 → QQ 群 → Telegram → Facebook → X（Twitter）→ WhatsApp → Instagram。正式顺序由 channels 数组决定；primary=true 的第一项默认展开，没有标记则展开第一项。其他项默认收起，用户可独立展开。enabled=false 的渠道不显示。

微信/QQ 用于一对一服务，公众号用于通知，群用于交流；海外即时咨询可选择 Telegram、Messenger、WhatsApp，Facebook/Instagram/X 主页承接品牌内容。根据实际服务地区和有人维护的渠道设置 primary，不承诺所有主页都有即时客服。服务时间须包含实际时区，例如 09:00–21:00（UTC+7）；具体语言与响应时间写入各渠道 description。

## Facebook 与 Messenger

1. 由业务负责人使用真实受控账号进入 Facebook 的创建主页入口，按平台要求创建品牌 Page，填写名称、类别、简介、头像、营业信息和网站。
2. 获取实际主页公开 URL 和名称；开启可用的消息入口后，验证真实 Messenger 联系链接。主页浏览与发私信是两种操作，分别填写 link 与 contact_link。
3. 通过平台现有权限功能分配运营人员访问权限，保留负责人和恢复方式；不把个人登录密码作为多人协作方式。
4. 在真实海外设备及未关注主页的账号上验证可访问性、消息入口及回复流程，再把配置发布到客服页。
5. 运营建议：置顶介绍、营业时间与点餐入口；主页发餐品及活动内容，具体订单问题转入私信处理。

官方资料：
- 创建主页：https://www.facebook.com/help/104002523024878
- 用户名与公开链接：https://www.facebook.com/help/162586890471598
- 查看主页访问权限：https://www.facebook.com/help/510247025775149/

页面字段：kind=facebook；account=真实主页名称；link=实际 Facebook 主页 URL；contact_link=已验证的 Messenger 链接；qr_image=上述主要公开链接对应的二维码图片。若未开通消息，则不配置 contact_link，不显示私信按钮。

## X（Twitter）

1. 从 X 官方入口注册，使用业务管理的邮箱或手机号完成验证，设置真实品牌名称和可用用户名。
2. 完善头像、封面、简介、网站和服务信息；根据官方当前资格选择 Professional Account，不将认证标识或广告开通当作普通链接展示的前置条件。
3. 将实际公开主页 URL 配入 link。页面按钮使用“访问 X 主页”，不假设所有用户都能向该账号发送私信。
4. 置顶介绍及点餐/客服入口，持续发布有用的餐品、营业与服务信息；公开回复引导具体订单问题走主客服。

官方资料：
- 注册：https://help.x.com/en/using-x/create-x-account
- 资料设置：https://help.x.com/en/managing-your-account/how-to-customize-your-profile
- 商业运营：https://business.x.com/en/basics/get-your-business-started-with-x

## Telegram

创建或使用业务方实际控制的账号，设置公开用户名；填写完整 @用户名和已验证的 t.me 链接。个人客服、公开群与私有群邀请是不同目标，不能根据群名称自行拼接邀请链接。私有群链接更新或失效后同步更换二维码。描述中区分“客服私聊”“技术支持群”“通知频道”。

官方资料：https://telegram.org/faq#usernames-and-t-me

## WhatsApp

使用实际业务号码完成 WhatsApp / WhatsApp Business 的注册验证；填好营业信息和回复安排，获取并验证官方 click-to-chat 链接后配置。account 展示带国家区号的号码；link 使用真实 wa.me 链接。不要用任意示例号码生成可联系陌生人的客服入口。

官方资料：https://faq.whatsapp.com/5913398998672934

## Instagram

创建或使用真实品牌账号，完善名称、简介、网站与头像，根据平台资格设置专业/商业资料。link 配实际 Instagram 主页；页面称“访问 Instagram”，不把主页链接写成保证可用的私信入口。适合菜品图片、门店视频和品牌内容，与主客服保持一致的服务说明。

官方入口：https://help.instagram.com/502981923235522

## 接入与运营交付顺序

1. 运营方准备品牌名、标识、受控邮箱/电话、目标地区、服务语言、营业时间及负责人。
2. 完成各平台实际申请和验证，记录真实账号、公开主页和可用私信链接；申请入口、验证码、审核及条款由账户负责人处理。
3. 验证主入口后生成对应正式二维码；微信、公众号、QQ 群使用平台提供的正式二维码。
4. 后台按上述顺序提供 channels，选择实际可服务的 primary 渠道；没有开通的渠道设 enabled=false。
5. 逐项检查网页、App、小程序及海外设备：能否访问、链接指向、扫码目标、复制内容、消息能否被业务团队接收。
6. 运营初期先维护少量可回复的渠道，再按实际需求扩展。建议统计来源和响应时效；任何自动消息、广告投放和平台 API 接入均另行核实授权、审核与费用。

本次提供的是公开联系方式接入，不要求购买平台 API 才能展示。广告、认证订阅、商业消息平台等属于独立产品，费用和资格以各平台当前规则为准。不要把历史企业 QQ/企点套餐当作普通 QQ 联系方式的必需费用。
