- 收藏：确认框改为项目既有回调适配，确认期间加锁；成功后立即移除并反馈，再刷新分页；缺图展示占位。

真实支付需后端确认发卡；Mock 为每个顾客提供独立的演示卡包，可使用 GIFT-DEMO 再兑换一次测试卡，再验证赠送、撤回与跨账户领取。没有通过支付弹层伪造购买成功或自动增加资产。H5 不具备微信小程序原生分享能力。
