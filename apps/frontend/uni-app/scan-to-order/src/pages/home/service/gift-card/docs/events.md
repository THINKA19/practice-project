# 礼品卡链路验收

事件字段由 [流水模块](../../gift-card-logs/docs/db.md) 唯一维护；各领域的文件和状态归属见各自 README。

## 开发链路

1. 现有开发 Mock 与演示客户登录下，卡包初始七张卡，覆盖储值、次卡、赠送中、领取、过期及耗尽。
2. 详情先加载 20 条流水，再加载到 24 条，显示到底；流水失败保留卡片资料，重试不跳页。
3. 模拟购卡、消费及返还只改变演示资产；同一笔消费不能重复返还。
4. 使用 GIFT-DEMO 兑换，每账户一次；成功返回我的卡包。
5. 赠送签发、撤回后凭证失效；预览不转移资产，领取后原持有人失去卡片，接收人只看到领取事件。
6. 到期清理只产生一次过期事件；账户、卡片或留言变化后，迟到响应不能恢复旧凭证。
7. resetAllMocks 分别重置资产、兑换、分享、流水；领取不保存第二份状态。

## 未验证的真实能力

生产支付发卡、订单扣卡与退款、并发领取及幂等、微信双设备分享仍需后端和真机联调。开发内存状态不跨设备共享。生产构建需要验证公共 loader 和所有业务 Mock 均被既有构建机制排除。
