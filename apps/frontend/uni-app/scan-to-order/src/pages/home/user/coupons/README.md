# 优惠券

正式路由：`/pages/home/user/coupons/index`。首页用户卡和会员中心均可进入。页面提供可领、可用、失效和兑换四个标签。

- `use-page.ts` 维护标签和列表状态，`use-view.ts` 将其接入 z-paging。每页 15 条，支持下拉刷新和触底追加；切标签、换账户和销毁后忽略旧列表响应。兑换标签不请求列表。
- `use-fetch.ts` 负责领取、口令校验和错误提示。领取中禁用重复提交；成功后记录本会话已领取状态，重新进页依赖服务端字段。
- `use-exchange.ts` 负责兑换表单和提交。成功后保留券号、清除密码，失败保留输入供重试；换账户时清除表单和领取口令。
- `api/` 维护端点与请求，`models/` 解析券模板、持有券及分页响应，`domain/` 存放不依赖页面的规则。跨模块调用经 `index.ts`。

“去使用”先读券详情：通用券跳点餐页，限范围的券跳自取选店页；实际适用范围以结算为准。页面分享使用正式路由和当前顾客会话。

开发 Mock 允许游客预览样本；领取和兑换仍要求顾客身份。领券口令：`DEMO`；兑换券号：`DEMO2026`，密码：`DEMO`。接口与生产待确认项见 [接口契约](docs/db.md)。

局部验证：`pnpm test:run src/pages/home/user/coupons`。
