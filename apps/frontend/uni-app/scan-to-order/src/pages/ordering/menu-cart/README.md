# 购物车与桌台订单

源码核对：2026-10-28。

## 页面与职责

`index.vue`：购物车；`order.vue`：桌台已点订单。

拥有购物车接口、协议转换、数量规则、共享快照和桌台订单页面编排。账户订单实体及桌台写入接口继续由账户订单领域拥有。

## 公开能力与依赖

`cartApi`、`useCartStore`、CartItem、AddCartCommand 和订单商品转换/数量规则。

依赖：menu 商品规则/文案及 Mock 样本；共享会话；账户 profile/order。

跨领域只通过对方 index.ts；页面只由路由加载，内部组件使用 components/组件名/index.vue。

## 状态所有权与规则

非营业仍允许查看、增减和删除购物车商品。桌台提交前复用门店 `useShopCheckoutAvailability` 刷新并检查经营状态，失败保留购物车且不发送加菜请求；按钮显示不可结算原因并置灰。该前端检查不替代真实后端对桌台写入的原子校验。

`store.ts` 是购物车快照唯一所有者，切换会话立即失效；页面只读该快照。桌台订单属于 useCartTableOrderPage 页面实例。

切换当前门店或扫码桌台时同步清除本地快照并使旧请求失效；当前门店只展示 `shopId` 匹配的商品，数量、金额重新汇总。清空按条目删除本店商品，保留其他店商品；返回原店从服务端重新读取。普通确认订单通过同一 Store 读取门店快照，不直接使用整车响应。无门店的历史接口调用保持原协议，菜单底栏要求已选门店才显示。

购物车以服务端为事实源，不持久化第二份商品。读取使用请求版本隔离乱序；清空、删除和换身份使旧读取失效。删除失败向调用方报告，保留已有快照。页面通过 Store 更新数量和清空，避免旁路更新导致页面状态分叉。
