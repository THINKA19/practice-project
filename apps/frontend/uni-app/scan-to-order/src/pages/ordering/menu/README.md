# 菜单选品

源码核对：2026-10-28。

## 页面与职责

`index.vue`：普通/扫码菜单；`notice-detail.vue`：菜单公告详情。

拥有分类、商品搜索、规格/加料/时段选择、SKU 询价、拼团及菜单公告。goods/list.vue 通过公开入口使用列表流程，不复制接口与状态。

## 公开能力与依赖

`catalogApi`、`pingtuanApi`、`useOrderingSkuSelection`、商品卡片与快选组件、商品类型和规则；保留现有文案、平台与错误适配出口。

依赖：门店上下文、购物车、结算购买草稿、账户会话、首页 Banner 与现有请求/分页/导航能力。

购物车底栏使用公共 `@/components/cart-bar`，页面传入数量、金额、币种、翻译文案和营业状态，并处理购物车/结算/获取门店事件；底栏不直接依赖点餐业务。购物车弹层仍归本领域。

`use-cart-bar-binding.ts` 复用 `use-page.ts` 已创建的购物车和门店实例，统一组装底栏属性、显隐及事件。底栏内部 Hook 管理展示与点击保护；购物车异步锁、数据和结算流程继续由原业务 Hook 管理。

跨领域只通过对方 index.ts；页面只由路由加载，内部组件使用 components/组件名/index.vue。

## 状态所有权与规则

门店统一可进入浏览和加购；休息中、暂停营业及尚未开业时，顶部说明仅供浏览，底栏显示具体不可结算原因。去结算及拼团直接购买复用门店 `useShopCheckoutAvailability`，刷新失败或经营状态不允许时不跳转；规格和数量操作不增加经营状态限制。购物车不锁定库存、价格或优惠。

分类分段、搜索、弹窗、选中规格、报价和公告属于页面实例；购物车归 cart，购买草稿归 pay，当前门店归 index。本模块不持有第二份共享购物车。

组件按 catalog、selection、cart 分组，GoodsList 的 GoodsCard 仅作私有 parts。规格选择和纯计价规则分别位于 composables、domain；旧报价不得覆盖新选择或已销毁页面。分页失败显示重试，空结果与失败分开。

## 验证边界

本地 Mock、单元测试和构建不代表真实后端、支付、地图网络及设备行为已验证；无权威后端资料的表结构、状态枚举与业务约束保留待确认。

商品搜索页面及专属流程归 menu-search；本领域保留共享商品接口、模型、Mock 和规格能力。

## 跨门店演示与空状态

除莲香米粉中心店（第三条门店，ID 100）外，其余 25 家登记门店沿用 36 个通用演示商品。莲香中心店独立配置 5 款米粉与越南冰咖啡，分类为招牌米粉、鸡肉米粉、粉店饮品；米粉小/中/大份独立售价，辣度与粉种同价，鸡蛋/牛肉为收费加料。商品 ID 独立，详情、规格报价与购物车加料校验使用对应商品。越南/老挝的新样本金额按万计，泰国按铢计，仅为测试数据，不代表真实菜单价格。

分类 Mock 按请求门店返回有商品的分类。运行时逐分类确认空数据后移除对应导航，整店无商品时隐藏侧栏，显示“本店暂无在售商品”及切换门店提示；加载中、加载失败和正常空菜单分开，失败提供重试，不把请求失败当成空分类。

活动轮播固定 110rpx 高，不依赖商品数量；有一张图时静态展示，多张时轮播，无图时隐藏整个活动区，不制造空图片。

## 全局广告轮播

公共 banner-carousel 位于消息提示下面、门店栏上面，横跨页面内容区，固定 150rpx，右上角标注广告。独立 adBanners 状态只在页面初始化时请求，不传门店参数，选店和 onShow 刷新菜单不重新请求它。单图静态、多图轮播、无有效图片或请求失败时隐藏。点击复用既有 Banner 链接处理；演示广告未配置跳转目标。

复用 bannerApi.banners('ordering_ad')，Mock 已提供三张本地演示图；ordering_ad 为本次新增的前后端待联调类型，需要后端 /banner/list 支持。下方原有 diancang 轮播保留，本次未调整其接口或门店归属规则。

## 加购反馈

列表加号请求期间使用按钮内加载动画，成功后依赖商品角标、购物车数量和金额更新，不再显示系统成功 Toast，不额外叠加购物车弹动。加购不调用全屏遮罩 loading，同商品尚未完成的请求合并，其他商品可独立加购。规格提交按钮显示加载并禁用重复提交，仅成功时关闭弹层；失败或需要登录时保留当前选择，错误与登录处理沿用原流程。购物车加减使用行内加载，同条目请求期间防重复；清空位于标题栏，确认后显示按钮内加载，期间禁止加购、加减和结算。数量修改期间清空按钮保持可用与原有样式，主动清空确认后等待当前更新结束再执行清空；结算按钮保持颜色稳定，主动点击后等待当前修改完成，失败不跳转，等待期间禁止新增修改。空购物车隐藏底栏。名称与价格保留间距，空间不足时操作区换行，数量角标归属购物车图标。当前源码未发现独立飞入购物车动画，本次未新增该动画。

## 公共规格选择组件

选项 UI 统一使用 `src/components/goods-sku-selector/`，公共 Hook 负责受控点击、禁用校验与选择汇总；菜单弹窗、快速选择和商品详情的业务组件转换数据与价格文案。页面数量、询价、时段规则和购物车动作仍由原业务 Hook 维护，不新增全局共享选择状态。
