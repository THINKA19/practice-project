# 点餐组织与整理记录

本轮按项目 .agents/skills/uniapp-business-development 整理，领域与页面清单见 [ordering/README.md](../../README.md)，检查结果见 [VALIDATION.md](../../VALIDATION.md)，不在多个文档复制历史测试计数。

## 目录与边界

- 8 个页面领域共 10 个页面；商品搜索归 menu-search/index.vue，重复优惠买单页已收敛到账户 bill-pay，不复制接口或 Store。
- ShopPhotoGallery、ShopImagePreview 统一为独立目录的 index.vue，迁移实际页面、组件和测试引用。
- 位置页通过详情公开能力获取服务端地区名称；地区选择器通过门店接口获取开放目录，不再使用前端静态 shopRegions。
- ShopSelectionPage 只有本领域页面使用，移出公共出口，避免门店公开入口引入菜单流程形成循环。
- 商品详情内部直接引用本领域媒体 API；商品图片资料归 menu/mock/assets，menu-search 不保留孤立的 Mock 说明目录。
- 核心源码补齐文件说明、导出说明和示例；中文 JSON 使用配套说明；文档旧路径改为当前所有者。

## 流程与状态

- 购物车数量修改和清空通过唯一 Store；删除失败保留快照并报告，旧读取不覆盖新快照，清空后旧数据不恢复。
- 菜单分类异步任务与滚动定位在作用域销毁后失效；SKU 报价在切换商品或销毁后失效。
- 商品搜索区分加载、失败与空结果并提供重试；关闭快选或切换门店后忽略旧商品详情响应。
- 门店详情无效参数清空旧快照与标记，卸载后丢弃旧响应；位置页初始化同步清理详情，复制失败的旧回调不影响当前页面。
- 公告请求和状态归 useOrderingNoticeDetailPage，页面只组装生命周期与展示。API 返回原始协议，模型统一规范化；无效编号不请求，切换与销毁隔离旧结果。
